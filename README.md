# Two Things

A tiny browser-based app for tracking your two most important tasks each day.

## Features

- Focus on just two priorities
- Fun motivational messages as tasks are completed
- Animated UI with dynamic background changes
- No dependencies—just HTML, CSS, and JavaScript

## Running

Simply open `index.html` in any modern web browser.

## Future Ideas

- Persist tasks with localStorage
- Support more than two tasks
- Dark/light themes
- Keyboard shortcuts
